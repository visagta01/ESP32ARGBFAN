# Changelog – ESP32 ARGB Multi‑Fan Controller

## [1.0.0] – 2025‑01‑01
### Added
- Contrôle individuel de 3 ventilateurs ARGB
- Contrôle global (mode maître)
- Modes : OFF, Fixe, Pulser, Pulser+Couleur, Cycle Couleur, Timer
- Réglage manuel de l’heure interne
- Timer ON/OFF avec plage horaire
- Réglage de la vitesse des effets
- Interface Web simple et responsive
- Activation/désactivation individuelle et globale
- Code optimisé pour ESP32 classique
- README complet + licence MIT

### Improved
- Structure du code
- Gestion des animations
- Stabilité du serveur Web

### Planned
- Sauvegarde EEPROM
- Interface Web plus moderne
- Mode audio réactif
- Mode température CPU
- Support pour plus de ventilateurs
