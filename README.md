# 🎛️ ESP32 ARGB Multi‑Fan Controller

A complete ARGB controller based on ESP32 that allows you to manage multiple ARGB fans individually or simultaneously through a simple Web interface.

## ✨ Features

### Individual control
- ON / OFF  
- Static color  
- Pulse mode  
- Pulse + color shift  
- Color cycle  
- Timer mode  
- Adjustable effect speed  

### Global control (master mode)
- Control all fans at once  
- Global color  
- Global mode  
- Global speed  
- Global ON/OFF  
- Global timer  

### Manual clock
The user sets the current time manually.  
No Internet or NTP required.

### Simple Web interface
- Works on any browser  
- Mobile friendly  
- No heavy CSS  

## Hardware
- ESP32 DevKit  
- 3× ARGB 5V fans (WS2812 type)  
- 5V external power supply  
- 330–470 Ω resistors for data lines  
- Common ground
